# Two-step verification opt-out Implementation Plan

Source: `docs/superpowers/plans/2026-10-29-phase-1c-mfa-opt-out.md` (written 2026-10-29).

**Goal:** A user can turn off the second step of their own sign-in, and an admin can turn it off for a specific user (reset the factor, and exempt the user from the admin role's requirement), both through registered, audited, step-up processes.

## Tasks (2)
- Task 1: Kernel — exemption flag, hook, two processes, adapter method
- Task 2: Web — user menu dialog, admin user page actions, step-up copy, e2e, guides
